1. Introdução

1.1. Sobre o BookHub

O BookHub é uma aplicação web desenvolvida para proporcionar aos usuários um espaço centralizado para descoberta, organização e interação com livros. O sistema permite consultar informações sobre obras literárias e oferece recursos para que cada usuário possa registrar suas preferências e interagir com os livros disponíveis na plataforma.

A aplicação foi desenvolvida seguindo uma arquitetura composta por frontend, backend e banco de dados, permitindo a separação entre a interface utilizada pelos usuários, as regras e funcionalidades da aplicação e o armazenamento das informações.

Entre as principais funcionalidades disponibilizadas pelo sistema estão o gerenciamento de usuários, consulta de livros, autores e gêneros, avaliações, resenhas, favoritos e organização de livros em uma estante pessoal. O sistema também possui mecanismos de autenticação e controle das operações realizadas pelos usuários.

O BookHub foi desenvolvido utilizando tecnologias voltadas ao desenvolvimento de aplicações web, com HTML, CSS e JavaScript no frontend, Python e FastAPI no backend e PostgreSQL como sistema gerenciador de banco de dados. A comunicação entre a interface e o backend ocorre por meio da API desenvolvida com FastAPI.

O projeto foi estruturado de forma modular, buscando facilitar a manutenção, a organização do código e a futura inclusão de novas funcionalidades. A documentação técnica apresentada neste manual tem como finalidade apresentar essa estrutura e orientar a configuração, execução, manutenção e evolução do sistema.

1.2. Objetivo do sistema

O principal objetivo do BookHub é disponibilizar uma plataforma web que permita aos usuários descobrir, consultar, organizar e registrar informações relacionadas às suas leituras, reunindo diferentes recursos em um único ambiente.

Por meio do sistema, o usuário pode consultar livros disponíveis na plataforma, conhecer informações relacionadas a autores e gêneros e registrar suas próprias interações com as obras. Entre essas interações estão a atribuição de avaliações, a publicação de resenhas, a adição de livros aos favoritos e a organização das obras em sua estante pessoal.

Além das funcionalidades voltadas à experiência do usuário, o projeto tem como objetivo aplicar, de forma integrada, conceitos de desenvolvimento web, desenvolvimento de APIs, modelagem e gerenciamento de bancos de dados e arquitetura de software. A separação entre frontend, backend e banco de dados busca proporcionar uma estrutura organizada e facilitar a manutenção e a evolução da aplicação.

Dessa forma, o BookHub procura oferecer uma solução que combine organização de informações bibliográficas e interação dos usuários, ao mesmo tempo em que serve como aplicação prática dos conhecimentos técnicos utilizados em seu desenvolvimento.

1.3. Público-alvo do sistema

O BookHub é destinado principalmente a pessoas que possuem interesse em livros e que desejam utilizar uma plataforma para consultar, organizar e registrar suas experiências de leitura. O sistema foi desenvolvido para atender usuários que buscam centralizar informações sobre as obras que conhecem ou pretendem ler, além de registrar avaliações, resenhas, favoritos e organizar livros em sua estante pessoal.

A aplicação também considera diferentes níveis de familiaridade dos usuários com ferramentas digitais, buscando disponibilizar uma interface simples e intuitiva para a realização das principais operações do sistema.

Embora o público-alvo da aplicação seja composto pelos usuários finais interessados em livros, este Manual Técnico é direcionado principalmente a desenvolvedores, estudantes e responsáveis pela manutenção ou evolução do projeto. O documento apresenta informações sobre a arquitetura, tecnologias, estrutura de arquivos, configuração, execução e funcionamento dos principais componentes do BookHub.

Dessa forma, o manual serve como uma referência técnica para compreender a implementação atual do sistema e fornecer suporte para futuras correções, manutenções e implementações de novas funcionalidades.
